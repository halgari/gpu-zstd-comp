# Apple M4 Pro results (Metal), full Skyrim corpus

Date: 2026-09-30.
Machine: Apple M4 Pro (12 CPU cores, 16-core GPU, Metal 3), 24 GB unified memory, macOS 15.1, rustc 1.98.1, mains power.
Corpus: `data/corpus` (SMIM SE + Noble Skyrim 2K), `--ext dds,nif`, 3172 files, 100,754 blocks, 6,493,829,184 bytes. This is the same corpus as the 5090 results.
Builds: master `030ab8f`; run 3 uses branch `metal-exp` `86c2d9d`.
Every GPU run used `--batch max --inflight 3 --verify` and passed. MB/s figures are medians of 3 runs. Per-kernel times are ms/batch; for the s12 presets, k1 means k1_sort and k2 means k2_window.
Not fully idle: Parsec and Steam were running, and the load average was 0.9–3.1 before each set.
Measured by a peer session on the Mac.

## Larger batches don't help: `--vram-budget-mb 12288`

Kernel time scales linearly with batch size. On unified memory, the host upload writes grow from 3–13 ms/batch to 180–2030 ms/batch, because the 6.5 GB corpus plus about 12 GB of GPU buffers push the machine into swap. The worst case was rung1 at 260/590/460 MB/s across the three runs.

Keep the default budget on 24 GB Macs. On unified memory, the budget should be derived from (RAM − working set).

## GPU vs CPU, and hybrid

Best GPU setting against the best CPU thread count:

| GPU preset | GPU MB/s | CPU level | CPU MB/s | CPU advantage |
|---|---:|---|---:|---:|
| lvl3 | 568 | L3 | 4821 | 8.5× |
| lvl9seg | 612 | L9 | 721 | 1.2× |
| opt14 | 231 | L14 | 295 | 1.27× |
| opt16 | 167 | L16 | 259 | 1.55× |

**On this machine the GPU never wins alone.**

The hybrid runs the GPU (SG32 build) at the same time as the CPU on 8 threads:

| pairing | concurrent GPU MB/s | concurrent CPU MB/s | combined | best CPU alone (12T) | gain |
|---|---:|---:|---:|---:|---:|
| opt16 + L16 | 165.4 | 200.8 | 366 | 259 | +42 % |
| opt14 + L14 | 229.5 | 205.0 | 435 | 295 | +47 % |

Running together costs the GPU about 1 % and the CPU 3–10 %.

## Takeaways

- Apple Silicon is a correctness target. Its speed only comes as a hybrid alongside the CPU, which is a product decision because CPU blocks are byte-different from GPU blocks.
- Land `SG32` and `K1_GROUPS=32` as Metal defaults: +4–27 %, byte-identical output.
- Size the budget from RAM on unified-memory devices.
- `fetch-corpus` needs `7z`. On macOS, install it with `brew install p7zip`.
